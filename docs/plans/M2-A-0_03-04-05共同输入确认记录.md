## 3. 权威与责任确认

| 责任主体 | 唯一权威或责任 | 只读消费者 | 明确不负责 | 不确定时结果 |
|---|---|---|---|---|
| Java/MySQL | 会话、任务、执行、`attempt`、终态、结果和引用的唯一持久权威 | Python Runtime、Adapter、检索服务、审计 | 不以 Python 临时状态作为恢复或终态权威 | 拒绝状态推进或结果接受，保持/进入由 03 冻结的确定状态 |
| Python Runtime | 单次执行内的临时 AI 编排状态 | Java Agent | 不拥有跨重启恢复、持久状态、终态提交或权限扩展权 | 停止当前处理并返回类型化失败；Java 裁决状态 |
| `auth-service` | 身份、租户、角色和 RBAC 上界权威 | Java Agent | 不拥有 Agent 字段策略、模型准入或 Tool 授权 | Java 失败关闭，不使用缺失、冲突或过期事实 |
| Java Agent | 字段策略、模型准入、最终权限组合、执行预算和 Tool 授权权威 | Python Runtime、Adapter、检索服务、审计 | 不把最终裁决委托给 Runtime、模型、Adapter 或检索服务 | 拒绝模型/Tool/业务调用，不以默认值放行 |
| 检索服务 | 验证 Java 独立服务身份，校验并执行不可扩权硬过滤；拥有 ES/Embedding 内部重试 | Java Agent | 不重新授权、不放宽数据范围、不复用 Runtime 凭据、不承担 Agent 级融合/回答 | 授权、过滤、围栏或兼容状态不确定时失败关闭 |

确认结论：不存在双重状态权威或双重权限权威。下游只能校验、拒绝或收紧 Java 已确定的范围，不得补全、放宽或重定义。

## 4. 公共术语确认

下表冻结跨专题共同含义，不冻结字段名、JSON Schema、数据库列、枚举编码、凭据载体或实现签名。

| 术语 | 规范含义与唯一语义所有者 | 只读消费者 | 生成与失效时点 | Java / Python / 存储 / 审计含义 | 缺失、冲突、过期时 | 目标权威文档 |
|---|---|---|---|---|---|---|
| `request` | 调用方提交的一次逻辑需求及幂等边界；生命周期语义由 Java Agent 拥有 | Python、Adapter、检索 | Java 接受并校验入口请求时建立；完成响应不改变历史审计关联 | Java 建立并关联执行；Python 只读；存储方式由 03 冻结；审计关联原始需求 | 不创建执行；返回确定性入口错误 | 03 |
| `execution` | Java 为处理一个逻辑需求创建并持久控制的一次执行实例 | Python、Adapter、检索 | Java 短事务创建；进入终态后不可重新打开 | Java/MySQL 权威；Python 只持本次临时副本；存储终态单调；审计关联全部尝试 | 拒绝处理或结果提交 | 03 |
| `attempt` | 同一 execution 下由 Java 分配的有界尝试世代，不是新 request | Python、Adapter、检索 | Java 在获准重试时生成；被新 attempt、取消、超时或终态淘汰 | Java 决定编号/版本；Python 只回显；存储关系由 03 冻结；审计记录每次尝试 | 不调用下游、不接受结果 | 03 |
| `deadline` | 由 Java 建立并传播的单一绝对执行截止时间；任何重试不得延长 | 所有下游 | 创建 execution 时建立；到期后永久失效 | Java 计算剩余预算；Python/下游只收紧；必要持久字段由 03 冻结；审计记录超时原因 | 立即失败/超时关闭，不改用新 deadline | 03 |
| `cancellation` | 对当前 execution/attempt 停止工作的控制事实；终态裁决仍归 Java | Python、Adapter、检索 | 可信取消源触发；Java 持久化并传播；终态后只保留审计意义 | Java 记录/裁决；Python 尽快停止；存储事实由 03 冻结；审计记录来源与竞争结果 | 不得自行推断取消成功；按 Java 当前状态失败关闭 | 03 |
| `terminal state` | `SUCCEEDED/FAILED/CANCELLED/TIMED_OUT` 的单调最终状态，唯一提交者为 Java/MySQL | 所有下游 | Java 通过持久化并发控制提交；提交后不可回退或被迟到结果覆盖 | Java/MySQL 唯一事实；Python 无提交权；审计记录裁决与版本 | 拒绝迟到提交并保留诊断 | 03 |
| `subject` | 经 `auth-service` 证明、供 Java 授权组合使用的可信主体 | Python 只接收最小投影；检索不推断 | 请求鉴别时产生；认证失效、撤权或新鲜度超限时失效 | Java 验证并最小投影；Python 不补全；是否持久化由 04 冻结；审计使用安全标识 | 失败关闭 | 04 |
| `tenant` | `auth-service` 证明的租户隔离上界 | Python、Adapter、检索 | 随可信身份上下文建立；切换、撤权或过期时失效 | Java 绑定执行/权限；Python 不改写；存储/审计不得跨租户混用 | 失败关闭，不采用默认租户 | 04 |
| `capability` | Java Agent 授权的一项受控业务能力，不等同于模型建议或任意 operation | Python、Adapter、Tool Gateway | Java 授权决策时确定；权限/策略/执行失效时失效 | Java 组合权限与预算；Python 只在获准集合内编排；持久/审计绑定执行 | 拒绝调用或计划 | 04 |
| `data classification` | 来源属性和 Agent 版本化字段策略共同约束的数据敏感等级；Java 形成最终可用分类 | Python、模型、Tool、日志链路 | 数据进入处理边界时验证；来源/策略变化或不可验证时失效 | Java 判定模型准入与投影；Python 不判域扩权；存储/审计按最小披露 | 未分类或混合且不可由获准高信任能力处理时拒绝 | 04 |
| `policy version` | Java 最终权限组合、字段策略和模型准入所绑定的版本事实 | Python、Tool、检索、审计 | 每次决策/重验时绑定；策略变化、撤权或新鲜度超限时失效 | Java 校验；Python 只回显/使用；存储与审计绑定 execution/attempt | 旧决策和旧投影不可复用 | 04 |
| `model target` | Java 经 `ModelAccessDecision` 准入的具体模型信任目标 | Python Runtime | 每次模型调用前确定；权限、分类、策略、目标证明或 deadline 变化时失效 | Java 唯一裁决；Python 不换目标；不作为 Python 持久状态；审计记录安全目标标识 | 不调用模型，不跨信任等级回退 | 04 |
| `Tool scope` | Java 授予某 execution/attempt/capability 的 Tool、参数、资源、次数和预算上界 | Python Runtime、Tool Gateway | 签发短期能力凭据时建立；终态、取消、超时、撤权、策略变化或凭据过期时失效 | Java 签发/验证；Python 只请求；服务端保存方式由 05 冻结；审计记录使用结果 | 拒绝 Tool 调用 | 05 |
| `correlation` | 贯穿 request、execution、attempt、Tool、下游调用和审计的安全关联语义；Java 负责建立和传播 | 所有下游 | 入口/执行创建时建立；业务结束后仍按审计保留策略有效 | Java 生成/校验；Python/下游只传播；存储/审计关联但不记录秘密 | 拒绝需强关联的写入/回调；仅保留安全诊断 | 03 |

后续每一批贡献必须同时具备：

1. operationId、调用方向、触发条件和唯一责任人；

4. 权限/安全投影字段的数据分类和禁止日志清单；
5. 正常、边界、未知字段、未知 discriminator、超限和错误 fixture；
6. SemVer 分类、旧/新制品矩阵、灰度顺序和回滚条件；
7. Java/Python 双端契约测试及验证命令。

满足清单只允许申请 `IMPL-01-013` 实施授权。M2-A-0、03/04/05 编写完成、独立评审或 M2-A 关闭均不构成 OpenAPI、代码、流量或生产授权。
