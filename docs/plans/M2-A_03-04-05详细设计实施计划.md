## 3. 总体范围与不变量

### 3.1 范围内

- 创建和完善 03、04、05 三份 L2 详细设计。
- 为每份设计建立 `REQ/CON → DR → IMPL → TEST → VAL` 追踪。
- 分别执行编写期自检、确定性文档校验和独立设计评审。
- 执行三份文档的联合收敛检查。
- 汇总 M2-A 关闭所需设计证据和未决外部证据。

### 3.2 范围外

- 未经明确授权修改 L0、L1、00、01 或其他关联设计文档；本轮仅按用户授权原子修正 03 的远程调用预算边界。
- 修改唯一 OpenAPI、生成物、fixture、contract lock 或 CI。
- 未经单独授权实施03/04/05代码、数据库、配置或测试；本轮OPEN-04-001代码、脚本、依赖、配置、受控SQL及3306数据库无损对齐、测试、证据和Git提交推送已获明确授权，策略激活和生产动作仍在范围外。
- 启动 Runtime/Tool 服务、接入服务发现或承接业务流量。
- 目标系统质量通过、生产批准或生产生效。
- 将旧 `agent-*`、`es-*` 及历史设计作为目标实现权威。

### 3.3 全程不变量

1. Java/MySQL 是持久状态和终态唯一权威。
2. Java Agent 是字段策略、模型准入、最终权限组合和 Tool 授权权威。
3. Python Runtime 只持有单次执行临时编排状态。
4. 下游只能收紧，不得扩展 Java 已确定的权限、数据范围、预算或 Tool 范围。
5. 缺失、冲突、过期或不可验证的安全事实必须失败关闭。
6. 远程调用不得持有数据库事务、数据库锁或不可重入上下文。
7. 每条依赖只能有一个内部重试责任方，所有尝试共享同一绝对 deadline 和调用预算。
8. M2-A 或设计评审通过不构成 `IMPL-01-013`、其他代码、流量或生产授权。

### 4.2 权威与责任矩阵

| 责任主体 | 唯一权威或责任 | 明确不负责 |
|---|---|---|
| Java/MySQL | 会话、任务、执行、`attempt`、终态、结果、引用的唯一持久权威 | 不以 Python Runtime 临时状态作为恢复或终态权威 |
| Python Runtime | 仅持有单次执行内的临时编排状态 | 不拥有跨重启恢复、持久状态或终态提交权 |
| `auth-service` | 身份、租户、角色和 RBAC 上界权威 | 不拥有 Agent 字段策略、模型准入或 Tool 授权 |
| Java Agent | 字段策略、模型准入、最终权限组合和 Tool 授权权威 | 不把最终裁决委托给 Runtime、模型、Adapter 或检索服务 |
| 检索服务 | 验证 Java 下发的独立服务身份，并执行不可扩权硬过滤 | 不重新授权，不放宽数据范围，不复用 Runtime 凭据 |

### 4.3 公共术语

必须完整冻结：

- `request`、`execution`、`attempt`；
- `deadline`、`cancellation`、`terminal state`；
- `subject`、`tenant`、`capability`、`data classification`；
- `policy version`、`model target`、`Tool scope`；
- `correlation`、`idempotency`、`fence`、`replay`。

每个术语至少记录：规范名称、唯一语义所有者、只读消费者、生成和失效时点、Java/Python/存储/审计含义、错误语义及最终目标文档。

本阶段不冻结具体 OpenAPI 字段、JSON Schema、数据库列名、凭据载体或实现类签名。

### 4.4 三条失败关闭规则

1. 权限、数据分类、凭据、策略版本或围栏状态不确定时，一律拒绝继续执行。
2. 不得通过降级、重试或默认值放宽权限、数据范围、模型准入或 Tool 调用范围。
3. Runtime 或模型不得自行补全缺失的身份、权限、数据分类、策略版本、围栏或其他安全事实。

每条规则都必须有唯一目标文档及后续 `CON/DR` 落点。目标文档尚未创建时只记录计划目标，不虚构编号。

### 4.5 01 契约边界

本阶段必须冻结以下边界：

1. 只冻结 03、04、05 共同使用的公共语义。
2. 不修改 Java↔Python 唯一 OpenAPI。
3. 后续任何 Schema 贡献必须满足 01 第 8.2.3 节七项完整清单：
   - `operationId`、调用方向、触发条件和唯一责任人；
   - request/response/error Schema 的 `required`、`nullable`、`default`、`enum`、`unknown` 和边界语义；
   - `requestId`、`executionId`、`attempt`、absolute deadline、取消和迟到结果字段；
   - 权限及安全投影字段的数据分类和禁止日志清单；
   - 正常、边界、未知字段、未知 discriminator、超限和错误 fixture；
   - SemVer 分类、旧/新制品矩阵、灰度顺序和回滚条件；
   - Java/Python 双端契约测试及验证命令。
4. 每一批 Schema 贡献必须另行取得 `IMPL-01-013` 代码实施授权。M2-A 关闭、设计评审通过或联合收敛完成均不构成该授权。
