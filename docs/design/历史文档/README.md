# 设计文档历史归档

本目录保存大版本重写前的设计文档，仅用于来源追溯和历史审计，不再作为当前设计或代码评审权威。

## 归档结构

- `2026-08-21-v0-baseline/`：2026-08-21 冻结的 14 份 L0/L1/L2 设计正文原文。
- `审计附件/`：重写前已经从业务查询 L2 主文档中分离出的历史审计记录。

## 使用规则

1. 当前有效设计始终以 `docs/ARCHITECTURE.md` 列出的 `docs/design/` 根目录文档为准。
2. 归档正文保持冻结时字节内容不变；其中相对链接、状态、门禁和实施结论只代表归档当时的上下文。
3. 新版文档通过“来源与取舍”章节说明来源、保留的有效决策和废弃/简化内容，不复制旧版修改流水。
4. `2026-08-21-v0-baseline/SHA256SUMS` 是归档正文的完整性清单。
