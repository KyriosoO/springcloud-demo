## 12. 原子同步记录

以下同步用于保持权威原子性，不改变逐文档计轮：

1. L0、Agent L1、L2-00/01/02/04：统一官方 Python LangGraph 单运行时、固定 StateGraph、`checkpointer=False`、全局失败路径和无第二状态权威。
2. L0 AD-13、Agent L1、L2-04：将禁入 State 的对象收敛为完整文档/未投影响应，允许只在请求内保存已授权、限量证据片段，禁止持久化与 trace 正文。
3. L2-02、L2-03：将字段权限拆成 filter/display/sort/group/metric 用途，禁用未冻结币种/单位/精度的金额聚合。
4. L2-02、检索 L1、L2-04、L2-05：同步 Search 的单个请求绑定委托凭证、检索前过滤和零越权泄漏合同。
5. 检索 L1、L2-05：保留单活动重建、无缺口切换与可回滚架构不变量；具体控制面推迟到来源一致性合同具备后设计。
6. L2-04、L2-05：同步 `indexedAt/logicalIndexVersion`、有界 SearchHit 与版本化质量门禁。
