## 4. Java 依赖结论

P0 不修改任何 POM。P1 的 Auth、Gateway、Employee 能力优先复用当前 Spring Boot/Security/Jose/Web/WebFlux/MyBatis/Test 依赖和 `common-security`；只有编译或测试证明现有依赖不足时，才在对应模块加入当前纵切必需依赖。

| 模块 | P0 结论 |
|---|---|
| `common-security` | 已有 OAuth2 JOSE、Resource Server、JWT encoder/decoder 与 secret provider 基础；需要新增 purpose/provider 代码，不需要预先增加库 |
| `auth-service` | 已有 Web、WebFlux、Resource Server 与 `common-security`；P1 不预设新增库 |
| `gateway-service` | 已有 Gateway WebFlux、Resource Server、JOSE；P1 不预设新增库 |
| `employee-service` | 已有 Web、MyBatis、MySQL、Resource Server 间接能力；P1 不预设新增库 |
| `mq-procedure-service` / `transaction-api` | P4 范围，P0 不增加依赖；Runtime/共享专项模型边界保持不变 |
| `es-query-api` / `es-query-service` | P2 以后处理；P0 不提前加入 Elasticsearch/Testcontainers 依赖 |

## 6. Agent 服务 JWT 本地材料约定

P0 只冻结非秘密合同和可复现的测试生成方法，不把 key 值写入 Git、日志、文档、Graph State 或 CI artifact。

| 项目 | P1 冻结值 |
|---|---|
| algorithm | `HS256`，每个 key 至少 32 bytes |
| key purpose | `AGENT_SERVICE_JWT` |
| active kid | `ACTIVE` |
| previous kid | `PREVIOUS` |
| active env reference | `AGENT_SERVICE_JWT_HMAC_KEY_ACTIVE` |
| previous env reference | `AGENT_SERVICE_JWT_HMAC_KEY_PREVIOUS` |
| issuer | `agent-service` |
| Auth audience | `auth-service` |
| service subject | `agent-service` |
| Auth scope | `agent.authorization.resolve` |
| Auth endpoint | `/internal/agent/authorization/resolve` |
| Employee delegated audience | `employee-service` |
| Employee delegated typ | `agent-business-delegated+jwt` |
| Employee delegated scope | `agent.employee.query` |

测试 key 由测试进程分别生成两个不同的 32-byte 值，并仅在内存中使用；固定夹具保存 token header/claims、签名结果和 key fingerprint，不保存可用于非测试环境的 secret。必须覆盖 active、previous、未知 kid、错 issuer、错 audience、错 subject、缺 scope、过期和 keyset 重叠。

## 8. 证据目录与命名规则

- 仓库内的人工基线记录：`docs/design/agent/evidence/<phase>/`。
- CI/本地运行产物：`artifacts/<phase>/<module>/<commit>/`。
- `<phase>` 使用 `P0`～`P7`；`<module>` 使用仓库模块名或 `cross-contract`；`<commit>` 使用完整 Git SHA。
- 允许保存：命令、UTC/本地时间、工具版本、退出码、摘要、测试 XML、覆盖率和脱敏日志。
- 禁止保存：JWT、secret、用户 Bearer、Prompt、正文、完整权限表达式、真实敏感数据。
- `artifacts/` 不作为源代码提交内容；需要长期保留时由 CI artifact 或外部受控存储按 commit 关联。
