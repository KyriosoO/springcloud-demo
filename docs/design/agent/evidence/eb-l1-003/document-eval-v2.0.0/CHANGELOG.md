# 版本变更记录

## 2.0.0-synthetic - 2026-07-16

- 沿用 `1.0.0-synthetic` 的60个模拟语料块和26个评价案例，未修改 qrel、答案、权限、时间或引用标注。
- 将报告 Schema 升级为不兼容的 `2.0.0`：`stratified_results` 必填，并固定 domain/scenario/tag 三类分层结构。
- 将无结构 `metric_evidence` 替换为事实声明、支持、引用和必要要点的可重算原始证据。
- 新增独立验证器，校验 case ID 精确集合、分层成员、自动安全事件、总体/分层指标、失败门禁和总判定。
- 禁止只信任报告提交的聚合值；任何聚合或门禁结论与重算结果不一致均判为无效报告。

## 1.0.0-synthetic - 2026-07-16

- 首次冻结60个纯模拟语料块、26个评价样本、9项指标及报告 Schema。
