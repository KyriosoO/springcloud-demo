# 版本变更记录

## 3.0.0-synthetic - 2026-07-17

- 按 MAJOR 版本规则将权限语义由文档级角色 ACL 调整为首期单语料库级访问模型。
- 全部114个语料块归入 `document-default`，统一为 `internal`，删除所有 `allowed_roles` 字段。
- 由 Java Agent 的 RBAC、DOCUMENT 能力、语料库权限码、启停状态、策略版本和撤权围栏组合形成最终访问输入。
- 增加语料库停用、权限撤销、围栏未收敛和策略版本不一致案例；无权限类案例要求零候选。
- 增加54个纯模拟干扰块，确保每个 Recall@50 计分案例的有效候选池大于50且至少有50个干扰项。
- 报告 Schema 与验证器升级到3.0.0，并增加单语料库、无文档 ACL、候选池和失败关闭语义校验。
- 本版本只形成固定评价包，不声明已在目标系统完成实跑或达到生产质量门禁。

## 2.0.0-synthetic - 2026-07-16

- 强化分层报告、案例原始证据、指标独立重算和安全事件防伪验证。

## 1.0.0-synthetic - 2026-07-16

- 首次冻结60个纯模拟语料块、26个评价样本、9项指标及报告 Schema。
