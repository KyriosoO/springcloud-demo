# EB-L1-003 DOCUMENT 评价证据入口与勘误

## 当前权威评价基线

- 固定评价包：[`document-eval-v3.0.0`](./document-eval-v3.0.0/)
- 数据集版本：`3.0.0-synthetic`
- 状态：固定包已冻结并通过静态完整性校验；目标系统质量实跑尚未执行。

固定包用于解除 DOCUMENT/权限安全 L2 的“版本化固定评价工件”前置条件，不代表目标系统已经达到质量或生产门禁。系统质量放行仍须在冻结的目标制品上生成实际运行报告，并使用包内验证器独立复算。

## v3.0.0 README 勘误

冻结目录禁止原地修改，因此保留 `document-eval-v3.0.0/README.md` 的原始内容，并在此给出权威命令解释。原 README 第 67 行把“第二条命令”误写为“验证实际运行报告”，正确映射为：

| 命令 | 正确用途 | 能否证明目标系统已实跑 |
|---|---|---|
| `python validate_evaluation_report.py --check-pack` | 校验固定包、权限语义、候选池和 SHA-256 完整性 | 否 |
| `python self_test.py` | 构造 Oracle 报告，验证验证器的重算、防伪与泄漏拒绝能力 | 否 |
| `python validate_evaluation_report.py --report <evaluation-report.json>` | 校验目标系统实际运行产生的版本化报告 | 仅当输入确为冻结目标制品的实际报告时可作为质量证据 |

退出码 `0` 只表示对应校验成功，不能把固定包校验或 Oracle 自测解释为目标系统质量通过。后续若重新发布评价包，应按 PATCH 版本规则将该勘误并入新目录；在此之前，本文件是 v3.0.0 的权威外部使用说明。
