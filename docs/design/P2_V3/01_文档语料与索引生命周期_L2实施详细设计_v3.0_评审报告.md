## 4. S0 阻断问题

复审后未发现遗留 S0。关闭 8 项：

| 序号 | 位置 | 问题 | 风险 | 修复结果 |
|---:|---|---|---|---|
| 1 | 原 RebuildRequest/source | caller 提交 sourceUrl/header/params | SSRF、redirect/DNS rebinding、credential 泄露 | 改为 registered DocumentSourceConnector + safe SourceSnapshotRef；endpoint/credential 只在 composition root |
| 2 | 原 RebuildRequest/ingest | caller 提交 target index、indexDefinition、documents/free Map | 越权覆盖 active/foreign index、动态 mapping/字段穿透 | Document 专用 request 不含 target/map；server 分配 physical index，internal handle 才能写 |
| 3 | 当前 generic controller | raw search/index/delete/bulk/rebuild 可按 `{index}` 访问 Document target | 绕过 ACL、schema/seal、source/release gate | DocumentIndexAccessGuard 检查 path/body/indirect alias；Document target 必须走专用入口 |
| 4 | 第二轮 idempotency | unique digest 同时含 key 与 request | 同 key 不同 request 生成不同 unique 值，无法返回 409 | 拆为 unique scope-key digest + semantic requestDigest，冲突后比较 requestDigest |
| 5 | 原 direct alias endpoint | caller 可直接 switch/rollback | 绕过 07 Gold/security/capacity/rollback Gate | 删除 direct Document alias DTO/endpoint；仅接受 07 package-private authorized command |
| 6 | 原在线读取 | 只冻结 alias 名称，未验证一个 physical target/manifest/report | alias race/multi-target 导致 channel 数据不一致或未发布索引可见 | 每 request 一次 resolve；0/多 target 拒绝；sealed manifest + attestation 形成 ResolvedIndexTargetRef |
| 7 | 第三轮间接 alias/credential | 非文档 alias 可指向 Document physical，generic/document 共用 ES credential | guard 名称规则被绕过，raw endpoint 可泄露或修改文档 | guard 解析 unknown alias target/manifest；generic role 排除 agent-doc，Document client 独立最小 role |
| 8 | 原 build success | partial/unknown bulk 无稳定确认和 sealed manifest | task 可能把不完整/漂移 corpus 标 SUCCESS 并被发布 | deterministic id、unknown read-confirm、stable digest、write block/read-back；manifest 未闭合不得 SUCCESS |

## 5. S1 严重问题

复审后未发现遗留 S1。关闭 13 项：

| 序号 | 位置 | 问题 | 风险 | 修复结果 |
|---:|---|---|---|---|
| 1 | 原 chunk schema | 每个 chunk 保存 retrievalProfile | query Profile 变化强迫重建索引，并与 02/00 alias owner 冲突 | Profile 完全移出 index；CorpusKey→alias/schema/connector 归 01 |
| 2 | 原 chunk schema | schema/index/model/dimension/snippet/context 重复 | 存储膨胀、多版本漂移、上下文全文重复 | index-level facts 归 manifest；snippet/context 查询期生成；embedding 排除 `_source` |
| 3 | 原 task/audit | RebuildTask 保存 validation，EsIndexAliasService 自建 audit/history | 01 与 07 形成 report/current-state 双权威 | task 只有 build status；07 唯一持有 report/change/audit/reconciliation |
| 4 | 原 alias 语义 | 把 ES atomic action 宣称为 CAS | 并发 initial activation 或外部修改可产生 multi-target/unknown | 07 exclusive lease + expected pre-read + must_exist action + mandatory post-read |
| 5 | 原 task | 无 unique semantic idempotency、lease/rowVersion/heartbeat/recovery | 重复 build、双 worker、崩溃后错误续跑 | 专用 task 表、CAS lease、protected cursor、lost-lease stop 和 recovery |
| 6 | 第二轮 attestation | build/request/attestation 绑定 releaseChangeId | 一次 rollout conflict 使有效 index 无法复用 | build 与 rollout 解耦；attestation 只绑定 immutable manifest/report |
| 7 | 原 alias API | switch/rollback 两套方法/状态 | 演进和异常路径重复 | 统一 compareAndSwitch；expected/target 表达 activate/rollback |
| 8 | 第三轮更新语义 | Document incremental/active write 未冻结 | active index 原地 patch 破坏 rollback/content digest | 当前只允许 FULL_SNAPSHOT→new physical；generic incremental 对 Document 拒绝 |
| 9 | 原 cleanup | cancel/failed index 由清理任务按 audit 自动回收 | unknown rollout/report/rollback window 下误删 | 07 retention authorization + 01 read-current/recheck/delete；无授权不自动删 |
| 10 | 第二轮影响范围 | 首轮拟删除 generic RebuildRequest/RebuildTask/service | 误伤非文档 es-query caller，违反最小必要修改 | 保留非文档 generic contract/service，只隔离 Document target；专用 use case 独立 |
| 11 | 原接口/数据/测试 | 只有省略路径和“DDL 另定”，缺 exact task/manifest/role/gate | 无法可靠编码，迁移易漏 raw endpoint/旧字段 | 补 22 个 Java 落点、逻辑表字段、V4/config/fixture、测试矩阵与命令 |
| 12 | 第四轮关联复审 | 01 声称 04 在一个请求内编排多个 CorpusKey | 与单 Validated Plan/单 Corpus/单 target/filter/evidence 约束冲突，迫使 leaf retrieval扩权和重做预算 | 当前一个 Plan/request只解析一个 Corpus；未来多 materialType归上层独立 child Invocation协调 |
| 13 | 第五轮模块复审 | Agent command直接引用es-query-api CorpusKey | agent-adapter-api需依赖ES wire模块，通用Adapter边界被具体设施反向侵入 | 同一DCK-1逻辑contract使用两个模块本地strict record；Adapter唯一映射并做contract test |
