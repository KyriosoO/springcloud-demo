## 4. 代码问题清单

| 编号 | 级别 | 类型 | 文件 | 问题描述 | 影响 | 处理结果 |
|---|---|---|---|---|---|---|
| CR-001 | high | authorization_sequence | `DocumentCapabilityHandler.java` | 原执行链在解析 Document ACL scope/currentness 前调用 query rewrite 与 embedding Provider | ACL 被拒绝、权限版本过期或权威源异常时，用户查询仍可能外发给第三方 Provider，违反 fail-closed 和最小披露边界 | 调整为 initial request → ACL scope → scope currentness → rewrite/embedding → retrieval；新增 ACL 拒绝时 Provider 零调用测试 |
| CR-002 | high | candidate_security_boundary | `DocumentCapabilityHandler.java` | 原执行链先将 Adapter 返回的 `AclBoundDocumentHit` 送入 rerank，之后才调用本地 `DocumentCandidateSecurityProjector` 校验候选安全绑定 | 被错误 Adapter、契约漂移或伪造响应污染的 title/snippet 可能先于本地绑定校验外发，且 OPTIONAL rerank 会吞掉 Provider 异常后继续处理 | retrieval 后立即完成全量候选安全投影；rerank 输入只从 `SafeDocumentCandidate` 构造，并校验 safe/raw 数量一致；新增错误 profile binding 下 rerank 零调用测试 |
