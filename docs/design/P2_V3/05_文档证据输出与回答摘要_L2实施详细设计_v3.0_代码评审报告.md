## 4. 代码问题清单

| 编号 | 级别 | 类型 | 文件 | 问题描述 | 影响 | 处理结果 |
|---|---|---|---|---|---|---|
| CR-001 | high | resource_limit_bypass | `DocumentEvidencePackingLimit`、`DocumentGenerationEvidenceProjector` | Provider 投影只受总 evidence/context 字符限制，未执行单条 `maxSnippetChars` | 单条文档可占满全部 Provider context，与冻结 Profile/ResourceLimit 不一致 | typed packing limit 增加 `maxSnippetChars`，Mask 后按实际出站文本在完整句边界截止 |
| CR-002 | high | citation_integrity | `DocumentCitationVerifier`、`DocumentResultSecurityProjector` | verifier 只要求 paragraph 末尾有 marker，中间 marker 可落入普通文本、URI、code/HTML；Result Security 只检查“单元中存在 marker” | 未绑定文本或伪造 marker 可被公开为 VERIFIED | 新增句末/单元末位置、整数溢出、URI/code/HTML 上下文检查；Result Security 投影前后均调用同一 verifier |
| CR-003 | high | data_minimization | `DocumentEvidenceVisibilityProjector`、`DocumentSafeSourceUri` | public visibility 仅检查 allowed field，未执行值级 Mask；URI 仅字符串删 query/fragment，可接受非 HTTP scheme/userinfo | 字段权限允许时仍可泄漏未脱敏值或输出不安全链接 | 注入 `ResultValueMaskingSupport`，统一对 title/content/snippet/context/page/URI 执行 Mask；共用 URI 收紧器仅允许 HTTP(S)、有 host，移除 userinfo/query/fragment |
| CR-004 | high | final_binding_gap | `DocumentResultSecurityProjector` | final decision 后未核对 citation document/chunk 与 candidate/hit 一致，coverage 整体直接复用 | 内存 DTO 被错误重组时可输出与 currentness 决策不一致的 identity/统计 | 按序核对 candidate-hit-citation document/chunk/citation ID，校验 offset/coverage/known flag，对 coverage/verification 深复制避免对象共享 |
| CR-005 | medium | aggregate_budget | `DocumentGeneratedTextCandidateFactory`、`DocumentCapabilityHandler`、`DocumentResultSecurityProjector` | summaryText 和每个 bullet 分别校验 `maxSummaryChars`，未校验总和 | 多 bullet 结果可数倍超过有效摘要预算 | 使用 checked arithmetic 聚合 summaryText + bullets，三个信任边界一致拒绝超限 |
| CR-006 | medium | selection_defense | `DocumentEvidenceSelector` | selector 未独立拒绝 duplicate candidateId/同 document-version 不一致 security binding，snippet 截止不优先完整句且未标记 truncated | 上游回归时可以不闭合身份进入证据链，coverage 也可误报未截止 | selection 前先验证完整输入的 candidate/binding，Unicode code point 截止优先最后完整句并置 truncated |
